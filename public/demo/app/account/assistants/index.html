Claude.ai and Claude Desktop
  1. Settings → Connectors → Add custom connector.
  2. Paste the address above, then authorize access on the page that opens (you can limit it to reading or to some spaces).
ChatGPT
  1. In ChatGPT's settings, turn on developer mode (Apps or Connectors section), then create a connector.
  2. Paste the address above, choose OAuth authentication, then authorize access. The search and fetch tools follow the format ChatGPT expects.
